OpenUnpack：密码库与批量解压

把已有密码整理成可检索的本地密码库，拖入文件或文件夹后自动尝试已保存密码，记住成功关联，让一批压缩包有明确、可重试的处理结果。暂用 OpenUnpack 作为项目名。

推荐架构与故障边界

桌面界面 → 批量任务编排 → 压缩引擎接口 → 官方 7z.dll；密码库 → DPAPI 加密文件。密码通过原生回调传递，避免出现在命令行。压缩包内容由安全路径检查后写入独立暂存目录，全部成功才改名为最终输出目录。

数据与隐私

密码记录：UUID、名称、Secret、分组、备注、启用、使用次数、最近成功时间。关联表记录压缩文件内容指纹 → 密码 UUID；历史记录结果和输出路径，设保留上限。整个数据库加密保存于当前用户 LocalAppData 中，不读取或迁移原软件私有数据库。

保存以临时文件加原子替换，读取失败进入明确错误状态，禁止用空库覆盖损坏库。备份使用随机 salt / nonce、PBKDF2-SHA256 和 AES-GCM；错误主密码或篡改应失败且不改变原库。明文 TXT/TSV 导入是用户显式选择的外部输入；导出只提供加密备份。

风险与接手说明

原生库是压缩格式解析的信任边界，需要及时更新；拒绝链接和路径逃逸，限制条目与解压大小。进程内 DLL 的崩溃隔离、跨平台、多任务并发、嵌套解压与文件夹监听均为后续工作。含多种密码、异构分卷与坏盘等极端场景应列在公开测试清单。

接手从 README 的构建命令开始，先运行测试，再使用独立测试数据手动确认拖放、文件选择、密码编辑、失败重试及取消。不得用用户个人密码库做回归夹具。
