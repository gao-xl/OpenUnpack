# 首版功能范围与交付总结

## 1. 架构与技术栈
- **运行平台**：Windows x64 桌面应用。日常解压与密码管理在本机运行；开发依赖下载、首次缺少 WebView2 的常规安装可能需要网络，不能承诺安装零网络依赖。
- **技术选型**：Tauri 2 + React + TypeScript + Ant Design 前端 UI。
- **核心机制**：Rust 本地协调器，解压与传输在独立 .NET Worker 进程中执行。控制/事件通道分离，监督与实际退出确认用于减少挂起影响；“完全无死锁”不是未经压力/故障测试可声明的保证。

## 2. 密码管理
- **组织与维护**：支持多分组、关键字实时搜索、密码项独立启用/停用、密码原文保存。
- **导入导出**：支持 TXT/TSV 批量导入，提供导入前解析预览与自动去重。
- **安全防护**：密码库使用 Windows DPAPI（用户账户绑定）加密保护；配置与任务路径元数据不以 DPAPI 加密。支持设置独立口令导出加密备份。

## 3. 归档识别与解压引擎
- **扫描与格式**：支持文件与文件夹拖拽录入并递归识别；支持 ZIP、7z、RAR 及其主流分卷归档。
- **轮试与记忆**：按策略对有限候选密码执行自动化轮试；解压成功后建立并持久化文件与密码的对应关联。
- **深度提取与容错**：支持双层嵌套内包自动提取；支持异常/中断时的部分解压结果按需保留。

## 4. 存储缓存与传输控制
- **SSD 缓存流转**：输入源与工作暂存可选置于 SSD 高速缓存目录，支持缓存配额控制与完成后的最终映射写回。
- **校验策略**：支持标准流式解压；提供可选的目标路径全量回读与完整性校验选项。

## 5. 任务队列与状态调度
- **调度控制**：默认单根顺序执行；队列暂停、继续，单任务/队列取消、失败重试。暂停/取消生效边界与验证证据见验收清单。
- **追踪与预览**：提供完整解压历史记录与异常恢复；排除规则支持实时预览影响文件范围。
- **稳定性与隐私**：错误按严重度分级上报；所有日志、提示信息与历史展示均强制敏感信息脱敏。

## 6. 核心默认准则与范围边界
- **首版默认策略**：保留源归档文件、不隐式排除任何文件、常规作业不上传、不后台查询云密码、单根串行队列。
- **可选处理策略**：单根目录剥离，以及完整验证成功后的源包回收站/删除。默认关闭；实际 Windows 行为、完整发布条件与故障验收单独检查。
- **首版不承诺特性（后续候选）**：密码空格变体推导、自动目录整理、完成后关机、压缩/打包制作、多盘并行、CSV 和云密码查询。

## 7. 协作授权与验收原则
- **开发授权**：用户现已授权正式恢复代码开发，并允许通过 Gemini 插件开展并行协作任务。
- **验收原则**：所有声明完成的功能必须经过实际代码测试或真实环境验证，严禁以规范草案或架构文档冒充代码实现。
